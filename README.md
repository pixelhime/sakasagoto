# 逆さ事 — 怪談ノベル

死んだ人に、生きている人の作法が通じてはいけない。

通夜の前夜、山あいの旧家へ一人だけ呼び戻された主人公は、伯母に教わりながら死者のための「逆さ事」を行う。屏風を逆さに立て、水に湯を足し、経帷子を左前に合わせる。朝までに、すべて元へ戻さなければならない。

日本の葬送習俗を題材にした、日英バイリンガル対応の短編ホラーゲーム。

## 遊ぶ

公開URL: https://pixelhime.github.io/sakasagoto/

または `index.html` をブラウザで直接開いても遊べます（ビルド不要）。右上のボタンで日本語／Englishを切り替えられます。

## 遊びかた

- 書付を読み、六つの品を死者のための向きへ整える。
- 夜の途中で増える二行に、従うか拒むかを選ぶ。
- 明け方までに、家の中の逆さ事を生者の向きへ戻す。
- 選択と作法の成否によって、四つの結末へ分岐する。

## 特徴

- 墨線・岩絵具・和紙を基調に統一した八点のイラスト
- 屏風、逆さ水、左前、枕飯、北枕などの文化解説（日英対応）
- WebAudioによるBGMと作法ごとの効果音
- 間違った作法に反応する微細な怪異演出
- 四つの結末と、到達済みの物語を読み返せる「結末帳」
- オートセーブ／日本語・英語切り替え／スマホ・PC対応

## 結末への行き方（ネタバレ注意）

| 結末 | 行き方 |
|---|---|
| **戻ス** | 夜の六作法をすべて正しく行い、自分の名を書かず、明け方の三品もすべて正しく戻す |
| **残ス** | 夜の六作法を一つ以上、生者のやり方で行い、自分の名は書かない |
| **左前** | 夜の六作法をすべて正しく行い、自分の名を書かず、明け方に一つ以上戻し損ねる |
| **招ク** | 過去帳に自分の名を書く（ほかの成否より優先） |

## 文化について

本作は日本の葬送習俗を題材にしていますが、作法には地域・宗派・家による違いがあります。ゲーム内でも、一般的な習俗と、この家だけのしきたりを分けて説明しています。

## 技術

依存ライブラリなし。HTML・CSS・JavaScriptとWebP画像のみで動作し、ビルド工程はありません。進行状況と結末の記録には `localStorage` を使用します。
